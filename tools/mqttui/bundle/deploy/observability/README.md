# Production observability assets

**Verified against `v1.0.16` (2026-09-11).** Grafana dashboards that ship with
the broker — not only inside the experimental `demo/` Compose stack
(ADR 0070 T4).

| File | What |
|---|---|
| [`grafana/mqttd.json`](grafana/mqttd.json) | Broker overview (operator signals, durable plane, hub). |
| [`grafana/mqttd-bridge.json`](grafana/mqttd-bridge.json) | Boundary-bridge dashboard; generated by `scripts/gen-bridge-dashboard.py`. |

The Helm chart's `PrometheusRule` (`deploy/helm/mqttd/templates/prometheusrule.yaml`,
`metrics.prometheusRule.enabled`) and the per-alert runbooks in
[`docs/OPERATIONS.md`](../../docs/OPERATIONS.md#shipped-alerting) are the other
half of shipped alerting.

The `demo/` and `bench/scale/observe/` Compose files **mount this directory**.
Do not keep a second copy under `demo/grafana/dashboards/` — that was the
drift class T4 closes.
